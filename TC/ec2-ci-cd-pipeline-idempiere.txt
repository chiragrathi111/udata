🛠️ STEP 1️⃣ — Put your script inside repo

Create file in your project:

scripts/build_and_upload.sh

Paste your logic (clean version 👇)

#!/bin/bash
set -e

echo "Detect changed plugins..."

CHANGED=$(git diff --name-only HEAD~1 | awk -F'/' '{print $2}' | sort -u)

echo "Changed plugins: $CHANGED"

rm -rf output
mkdir output

for plugin in $CHANGED; do
  echo "Building $plugin"

  mvn -pl $plugin -am clean package

  echo "Copying jar of $plugin"

  find $plugin/target -name "*.jar" ! -name "*sources.jar" -exec cp {} output/ \;
done

BUILD_ID=$(date +%s)

echo "Uploading to S3..."

aws s3 cp output/ s3://your-bucket/plugins/$BUILD_ID/ --recursive

echo "BUILD_ID=$BUILD_ID" > build.env


👉 🔥 Important:

This script will:
✔ Detect plugins
✔ Build
✔ Upload to S3
✔ Save BUILD_ID
🛠️ STEP 2️⃣ — Create buildspec.yml

Create file:

buildspec.yml

Paste:

version: 0.2

phases:
  install:
    commands:
      - echo "Installing dependencies"
      - mvn -version

  build:
    commands:
      - chmod +x scripts/build_and_upload.sh
      - ./scripts/build_and_upload.sh

  post_build:
    commands:
      - echo "Reading BUILD_ID"
      - export BUILD_ID=$(cat build.env | cut -d'=' -f2)
      - echo "Trigger deployment"

      - aws ssm send-command \
          --instance-ids "i-xxx" \
          --document-name "AWS-RunShellScript" \
          --parameters "commands=['bash /home/ubuntu/deploy_plugins.sh $BUILD_ID']"

artifacts:
  files:
    - build.env


👉 🔥 This is the main brain of pipeline
