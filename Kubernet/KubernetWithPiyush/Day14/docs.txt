Taint:- This is a applied to a node.
usecase:- 
1. If you want to avoid pod scheduling on specific node then we can use taint.
2. If you want to dedicate specific node for specific workload then we can use taint.


Toleration:- This is a applied to a pod.
tolerations:
- key: "node-role.kubernetes.io/control-plane"
  operator: "Exists"
  effect: "NoSchedule"


Taint created specific node and also provide which reason created
# kubectl taint nodes <node-name> key=value:NoSchedule
# kubectl taint node dev-cluster-worker2 gpu=true:NoSchedule
