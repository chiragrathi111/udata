deployment.yaml
spec:

   containers:

     {{- range .Values.env }}
        - name: {{ .name }}

     {{- end }}

Instead of always rendering env,
do This

{{- with .Values.env }}
env:
{{- range . }}
  - name: {{ .name }}
    value: {{ .value | quote }}
{{- end }}
{{- end }}

spec → template → spec → containers → env

I observe after run that command one zip file added on charts folder

3. after that updated values.yaml file that edit on bottom
redis:
  image:
    registry: docker.io
    repository: bitnami/redis
    tag: latest
  auth:
    enabled: false
This is a standard soevery time create 1 master and 3 replicas 

If we want only single master not a replicas 
redis:
  image:
    registry: docker.io
    repository: bitnami/redis
    tag: latest
  architecture: standalone
  auth:
    enabled: false

If we want 1 master and 1 replica
redis:
  image:
    registry: docker.io
    repository: bitnami/redis
    tag: latest
  architecture: replication
  replica:
    replicaCount: 1
  auth:
    enabled: false
