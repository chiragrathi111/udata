RBAC(Role Based Authorization Certificate):-
* access is based on the role of the user
* users are assigned to roles
* roles are assigned permissions
* users can have multiple roles
* roles can have multiple permissions
* permissions can be assigned to multiple roles
* RBAC is a popular access control model used in many organizations
* RBAC can be implemented using a variety of technologies, including databases, directories, and access control
