## Quick Test 🧪

After setup, test your registry:

```bash
# 1. Port forward
kubectl port-forward svc/docker-registry 5000:5000 &

# 2. Login
docker login localhost:5000 -u admin -p password

# 3. Push image
docker pull nginx:alpine
docker tag nginx:alpine localhost:5000/nginx:alpine
docker push localhost:5000/nginx:alpine

# 4. Verify
curl -k -u admin:password https://localhost:5000/v2/_catalog
```

See detailed troubleshooting in [STEP-BY-STEP-POC.md](STEP-BY-STEP-POC.md)

Common issues:
- PVC not binding → Check PV path exists
- Pods not starting → Check secrets exist
- Can't login → Check port-forward running
