I observer every ting is fine but docker have some problem that is the reason my container not up:-

Solutions:-
✅ Step 1 — Confirm DNS Problem

* docker run busybox nslookup google.com
If not getting responce then run below steps

✅ Step 2 — Check Your Host DNS

* cat /etc/resolv.conf
output:-
nameserver 127.0.0.53

That means systemd-resolved is managing DNS (very common in Ubuntu).

Step A — Edit Docker daemon config

* sudo nano /etc/docker/daemon.json

{
  "dns": ["8.8.8.8", "1.1.1.1"]
}

Save and exit.

Step B — Restart Docker

* sudo systemctl restart docker

Step C — Test Again

* docker run busybox ping google.com
output:-
